``# ✈️ 국내 여행 일정 & 맛집 추천 프로그램 (CLI 기반)

터미널 환경에서 여행 날짜를 입력하여 OpenAI와 Kakao API를 연동해 맞춤 여행지, 주변 맛집 정보, 1일 일정을 포함한 최종 여행 리포트를 자동 생성하는 파이썬 애플리케이션입니다.

---

## 🚀 실행 방법

### 요구 사항
* Python 3.10 이상
* 필수 패키지: `requests`, `python-dotenv`, `openai`

### 환경 변수 설정 (`.env`)
프로젝트 최상단에 `.env` 파일을 만들고 아래 API 키를 등록해야 합니다. 
```env
OPENAI_API_KEY="your_openai_api_key_here"
KAKAO_REST_API_KEY="your_kakao_rest_api_key_here"

```

### 실행 명령어

```bash
# 날짜 옵션(-date 또는 --date)을 지정하여 프로그램 실행
python travel_planner.py --date "YYYY-MM-DD"

# 예시
python travel_planner.py --date "2026-04-15"

```

---

## ✨ 기능 목록

* **입력값 검증**: 필수 옵션인 `--date`의 날짜 형식을 검증하며, 잘못된 형식 입력 시 사용법 안내 문구와 함께 즉시 종료합니다.
* **1차 여행지 추천 (OpenAI API)**: 입력된 날짜(계절, 시기)에 맞는 추천 지역, 날씨 요약, 행사/축제 후보, 추천 이유를 구조화된 JSON 데이터로 생성합니다.
* **지역 맛집 검색 (Kakao Local API)**: 추천받은 도시를 기반으로 카카오 장소 검색 API를 호출하여, 맛집 5곳의 상세 정보(이름, 주소, 카테고리, 좌표 등)를 수집합니다.
* **최종 리포트 생성 (OpenAI API)**: 수집된 지역 정보와 맛집 리스트(0건 포함)를 조합하여, 1일 일정 제안이 포함된 가독성 높은 마크다운(`.md`) 여행 리포트를 작성합니다.
* **유연한 예외 처리 (Fallback)**: 맛집 검색 결과가 0건이거나 지도 API 인증 실패 시 프로그램 중단 없이 해당 섹션을 '데이터 없음'으로 처리하고 다음 단계를 정상 진행합니다.
* **결과물 자동 저장**: 실행이 완료되면 `results/` 폴더 내에 원본 데이터 및 에러 로그가 담긴 JSON 1개와 최종 리포트 Markdown 1개가 자동 생성됩니다.

---

## 📂 주요 에러 처리 및 보안 정책

프로그램 운영 안정성과 데이터 보안을 위해 아래와 같은 정책이 적용되어 있습니다.

* **API 키 보안**: 소스 코드 내 하드코딩을 방지하고 `.env`를 활용하여 외부 유출로 인한 과금 폭탄 및 계정 정지 사고를 예방합니다.
* **키 누락 방어**: 필수 환경 변수가 감지되지 않으면 프로그램이 실행되지 않으며, 즉시 설정 방법을 안내합니다.
* **LLM 파싱 에러 복구**: 모델이 지정된 JSON 형식을 어기고 텍스트를 반환할 경우, 포맷을 재강조하여 최대 1회까지 자동 재시도를 수행합니다.
* **오류 로그 기록 (`errors`)**: API 호출 실패, 네트워크 타임아웃, 파싱 오류 등의 내역은 누락되지 않고 최종 JSON 파일 내부의 `errors` 배열로 요약되어 저장됩니다.
