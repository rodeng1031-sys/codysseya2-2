# 📗 기능 명세서 (Feature Specification)

## 프로젝트: AI 여행 추천 프로그램

---

## 🎯 프로젝트 개요

### 목적
사용자가 여행지를 입력하면 **AI(GPT)** 가 추천 문구를 생성하고, **Kakao API** 로 실제 장소를 검색하여 통합된 여행 정보를 제공합니다.

### 주요 기술 스택
| 분류 | 기술 |
|------|------|
| **언어** | Python 3.10+ |
| **AI API** | OpenAI GPT-4 |
| **지도 API** | Kakao Local API |
| **환경관리** | python-dotenv, venv |
| **테스트** | pytest, unittest.mock |

---

## 🔑 핵심 기능

### F-01: 여행지 추천 생성

**설명**: 사용자 입력 지역에 대한 AI 추천 문구 생성

| 항목 | 내용 |
|------|------|
| **우선순위** | ⭐⭐⭐ (필수) |
| **입력** | 지역명 (문자열) |
| **처리** | GPT API 호출 → 추천 문구 생성 |
| **출력** | 추천 텍스트 (100~200자) |

**시나리오:**
1. 사용자가 "부산" 입력
2. GPT에 프롬프트 전달
3. 추천 문구 생성 및 반환

**성공 기준:**
- ✅ 3초 이내 응답
- ✅ 지역 특성 반영된 내용
- ✅ 관광지/음식 정보 포함

---

### F-02: 실제 장소 검색

**설명**: Kakao API로 실제 관광지/맛집 정보 조회

| 항목 | 내용 |
|------|------|
| **우선순위** | ⭐⭐⭐ (필수) |
| **입력** | 지역명, 카테고리 |
| **처리** | Kakao Local API 호출 |
| **출력** | 장소 리스트 (이름, 주소, 카테고리) |

**성공 기준:**
- ✅ 최소 3개 이상 결과
- ✅ 실제 주소 포함
- ✅ 카테고리 분류

---

### F-03: 결과 통합 출력

**설명**: AI 추천 + 실제 장소를 통합해 사용자에게 표시

| 항목 | 내용 |
|------|------|
| **우선순위** | ⭐⭐⭐ (필수) |
| **출력 형식** | 콘솔 텍스트 (이모지 포함) |

**출력 예시:**
```
🧳 '부산' 여행 추천
📝 AI 추천: 부산은 해운대...
📍 주요 장소:
   1. 🏞️ 해운대 해수욕장
   2. 🍽️ 돼지국밥 맛집
```

---

### F-04: Mock 모드 지원

**설명**: API 없이 테스트 가능한 Mock 데이터 모드

| 항목 | 내용 |
|------|------|
| **우선순위** | ⭐⭐ (권장) |
| **용도** | 개발/테스트/데모 |
| **장점** | API 비용 절감, 오프라인 실행 |

## 🔒 비기능 요구사항

### 성능
- API 응답 시간: **3초 이내**
- 동시 요청 처리: 단일 사용자 기준

### 보안
- API 키는 `.env` 파일로 관리
- `.gitignore`에 `.env` 포함
- 코드에 하드코딩 금지 🚫

### 확장성
- 새 API 추가 가능한 모듈 구조
- 지역/키워드 확장 용이

---

## 🧪 테스트 계획

### 단위 테스트
| 테스트 케이스 | 대상 함수 | 기대 결과 |
|--------------|----------|----------|
| 부산 추천 | `recommend_travel("부산")` | 4개 장소 반환 |
| 알 수 없는 지역 | `recommend_travel("아틀란티스")` | 기본 문구 반환 |
| API 실패 시 | Mock 처리 | 예외 없이 실행 |

### 통합 테스트
- 전체 플로우: 입력 → API → 출력
- 3개 지역 (부산, 제주, 강릉) 연속 테스트

## 🚀 설치 및 실행

### 1. 환경 설정
```bash
# 가상환경 생성
python -m venv .venv
source .venv/bin/activate  # Mac/Linux

# 의존성 설치
pip install -r requirements.txt
```

### 2. 환경변수 설정
`.env` 파일 생성:
```env
OPENAI_API_KEY=sk-...
KAKAO_API_KEY=...
```

### 3. 실행
```bash
# 실제 API 사용
python main.py

# Mock 모드
python main.py --mock
```
